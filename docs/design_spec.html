1 System Architecture Overview

Brewline Cafe is an artisanal bakehouse and specialty cafe web platform. The platform operates on a serverless, decoupled architecture utilizing Next.js 16 App Router for presentation and API route handlers, paired with Firebase Cloud Firestore for real-time document synchronization and Razorpay for automated payments.

2 Business Logic Architecture

2.1 Role-Based Access Control (RBAC)

Role Permissions & Accessible Interfaces Enforcement Layer
Guest / Anonymous Browse catalog, add items to client cart, guest checkout with phone/email verification, track active orders via local storage ID tokens. Firestore Rules: Public read on /menu; Read on /orders if userId == 'guest'.
Registered Customer Save multiple delivery addresses, store profile preferences, 1-click reordering, submit post-delivery star ratings and review comments, live tracking. Firestore Rules: Strict ownership match (auth.uid == userId).
Kitchen Staff View incoming live orders in real-time on Kanban board, acknowledge receipt, update status (placed → preparing), toggle item stock. Firestore custom user role claim role: 'kitchen' or 'admin'.
Delivery Courier Inspect customer address, view delivery instructions, transition order to out_for_delivery and delivered. Role claim role: 'delivery' or 'admin'.
Super Admin Full CRUD over menu catalog, promotional discounts/coupons, real-time revenue analytics charts, customer support adjustments. Role claim role: 'admin'; full administrative Firestore access.

2.2 Order Lifecycle & State Machine

Orders strictly follow a finite state progression. Irregular state transitions (e.g. attempting to mark an order as delivered before preparing) are rejected by validation logic.

  • Placed: Razorpay payment verified or Cash on Delivery committed. Order enters the kitchen real-time feed.
  • Preparing: Kitchen staff confirms order. Estimated delivery time (EDT = placedAt + 25 mins) is computed and countdown activates on customer client.
  • Out for Delivery: Order is handed over to courier. Real-time ETA updates dynamically based on transit time.
  • Delivered: Courier completes handoff. Triggers automatic delivery invoice dispatch via Nodemailer and opens feedback rating modal.
  • Cancelled: Permitted only within 2 minutes of placement or by Admin if item is unavailable. Triggers Razorpay refund webhook.

2.3 Pricing, Cart & Mathematical Integrity Rules

To prevent client-side price tampering, all cart items submitted to /api/razorpay and checkout routes are re-calculated against active database records:

Subtotal: ₹ = ∑ (Item Unit Price × Quantity + ∑ Selected Addons)
Taxes (GST 5%): ₹ = Round(Subtotal × 0.05)
Delivery Fee: ₹40 (Waived to ₹0 if Subtotal ≥ ₹500)
Net Payable: ₹ = Subtotal + Taxes + Delivery Fee - Discount
Historical Price Snapshot Principle: When an order document is created, the system stores a fully-frozen JSON snapshot of each ordered item (name, unit price, addons, qty, line total). Any subsequent updates to menu item prices by the cafe manager will never retroactively modify the customer's historical order value.

5 Production Firestore Security Rules

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    function isAuthenticated() { return request.auth != null; }
    function isOwner(userId) { return isAuthenticated() && request.auth.uid == userId; }
    function isAdmin() {
      return isAuthenticated() && 
        (request.auth.token.role == 'admin' || get(/databases/$(database)/documents/users/$(request.auth.uid)).data.role == 'admin');
    }

    // 1. Users: Read/Write own doc; Admin full access
    match /users/{userId} {
      allow read: if isOwner(userId) || isAdmin();
      allow create: if isAuthenticated() && request.auth.uid == userId;
      allow update: if isOwner(userId) || isAdmin();
      allow delete: if isAdmin();
    }

    // 2. Menu: Public readable, Admin manageable
    match /menu/{itemId} {
      allow read: if true;
      allow write: if isAdmin();
    }

    // 3. Orders: Multi-tenant safety
    match /orders/{orderId} {
      allow read: if resource.data.userId == 'guest' || (isAuthenticated() && resource.data.userId == request.auth.uid) || isAdmin();
      allow create: if request.resource.data.status == 'placed';
      allow update: if (isAuthenticated() && resource.data.userId == request.auth.uid && 
                        request.resource.data.diff(resource.data).affectedKeys().hasOnly(['rating', 'feedback'])) || isAdmin();
      allow delete: if isAdmin();
    }

    // 4. Coupons & Analytics
    match /coupons/{couponId} {
      allow read: if true;
      allow write: if isAdmin();
    }
    match /analytics_daily/{dateId} {
      allow read, write: if isAdmin();
    }
  }
}
